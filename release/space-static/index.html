The decima package runs the same models and presets on a CPU, from Python, the command line or a local TypeSafe-compatible server.







  
Before you judge a model by this page. The examples are curated; the model cards have the benchmarks and the
  known limits. decima-guard checks prompts, documents, replies and web input for attacks and leaks (English, Arabic, Persian), and
  decima-guard-small does the same faster; decima-agent was trained for agent gates and knowledge-graph judgments in
  English; decima-base is the general, multilingual model; decima-small is the first generation, smaller and faster.
  Numbers are hard for all of them (thresholds, dates, counting).

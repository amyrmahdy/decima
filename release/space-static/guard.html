How it works

Pick what the text is, paste it or click an example, and press Check. The first check downloads the model once (it is then cached on this device). In a browser tab the first check takes a few seconds and later ones about a second; the same model in Python on a server CPU takes about 44 ms per question.

Why another guard
Most open guards were trained on English. On ordinary Arabic
    and Persian messages they raise false alarms on most of them, so real customers get blocked. Same frozen public test
    for both models, int8, CPU:

Weak spot: it misses about 1 in 6 real attacks translated into Arabic dialects, and about 1 in
    3 translated into Persian. Keep hard rules first and use the guard as one layer. Every test row and prediction is
    public in decima-guard-bench.






  
This is a preview. The examples are written by us to show each check, not taken from the test sets. The
  verdict uses a 0.5 threshold on each check; the probabilities are calibrated, so in your own code you can pick a
  stricter or looser one.

  
int8 ONNX on ONNX Runtime Web (WebAssembly), in this tab. It computes the int8 layers with float
  activations, so a probability can differ from the Python package by a few hundredths on close calls.
